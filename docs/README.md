## 为什么复制一份进仓库

厂商包 `MPU_example/` 下有一份**同名**的 `CY-Z协议.md`（6,328 B，2026-06-27），它是**上一代**文档，缺了三块关键内容：

| 内容 | 6 月版（厂商包内，已过时） | 9 月版（本目录，有效） |
|---|---|---|
| 上报频率**查询**命令 `Cmd=0x02` | 无 | 有（ACK 的 Result 直接返回频率码） |
| 上报频率**设置**命令 `Cmd=0x03` | 无 | 有 |
| 上报频率参数表 | 无 | 有：`0x00`=50 Hz、`0x01`=20 Hz、`0x02`=10 Hz、`0x03`=询问模式、**`0x04`=100 Hz**、**`0x05`=200 Hz** |
| I2C 寄存器协议（含 `SAMPLE_HZ`、状态位、断线恢复） | 无（整章缺失） | 有 |
| 串口/I2C 选择说明、各主机工程引脚表 | 无 | 有 |

- **不要混淆**：`SAMPLE_HZ`（I2C 寄存器 `0x06`，当前固定 `500`）是模块**内部采样率**；**UART 上报频率**（50/20/10/100/200 Hz）是另一回事。
- **规则**：涉及 CY-Z 协议的实现决策，以本目录的 `CY-Z协议.md` 为唯一依据；厂商包内同名文档不作为依据。
- 厂商 SDK 头文件里的"上报频率"枚举**只覆盖到 `0x03`**，比两份文档都旧一代 ⇒ 设置频率必须直接下发底层命令（`Cmd=0x03`），不要用带参数范围校验的 SDK 封装。

## 已确认的协议事实（速查）

- 模块 UART：115200 / 8 / N / 1 / 无流控。文档里写的 "USART1" 是笔误——模块只有一路 UART，与宿主挂哪个串口无关。
- 所有多字节字段 little-endian，CRC-16/MODBUS（初值 `0xFFFF`，多项式 `0xA001`，低字节在前）：

| 方向 | Header | 长度 | 用途 |
|---|---|---|---|
| 模块→主机 | `AA 55` | 16 B | 遥测：Seq / AngleDeg(f32) / GyroDps(f32) / CRC / `55 AA` |
| 模块→主机 | `A5 5B` | 8 B | ACK：Cmd / Result / Seq / CRC / `5B` |
| 模块→主机 | `A5 5C` | 12 B | 比例因子响应：Cmd / Seq / GyroScaleFactor(f32) / Reserved / CRC / `5C` |
| 主机→模块 | `A5 5A` | 8 B | 命令：Cmd / Param / Seq / CRC / `5A` |

- ⚠️ ACK 的 `Result` 含义**随 Cmd 而变**：`Cmd=0x02` 时 Result 是**频率码**（`0x00` = 50 Hz）；其余命令时 Result 是**状态码**（`0x00`=成功、`0x01`=设备未静止、`0x02`=命令或参数错误、`0x03`=执行失败）。同一个 `0x00` 两种语义，判定必须结合 Cmd 一起看。
- 接口模式选择脚：**高电平或悬空 = 串口（默认）**；接 GND = I2C。模块内部已上拉，切换电平后模块会自动改用对应接口。
- F103 例程的引脚分配是 I2C1 PB6/PB7 + 选择脚 PA0。本工程 **PB6/PB7 已用于 USART1 重映射**、**PA0 已用于 TIM2_CH1 外部计数** ⇒ 本工程只能走串口方式，且**不得**沿用该例程的引脚分配。
